## The enumeration audit

After a miss was found in the emil report, every multi-member set in all
three reader reports was re-counted against the clones. **4 of the 7
repos with member sets had unenumerated sets** (the two
`anthropics/claude-code` plugin rows are single artifacts with no member
set and are not audited below): the reader counts correctly, details the
interesting subset, and the count reads as coverage. *(This sentence
itself said "5 of 8" until 2026-07-31, when a reviewer counted the
table — an unenumerated set claim inside the audit of unenumerated set
claims.)*

| Repo (7 with member sets) | Members | Named in report | Verdict |
|---|---|---|---|
| obra/superpowers | 14 | 14 | clean |
| emilkowalski/skills | 8 | 3 | missed `apple-design`, `animation-vocabulary`, `find-animation-opportunities` |
| thedotmack/claude-mem | 18 | 8 | missed `oh-my-issues`, `smart-explore`, `babysit`, `version-bump`, +6 |
| pbakaus/impeccable | 22 sub-commands | ~6 | missed `harden`, `delight`, `critique`, `degraded/` |
| nextlevelbuilder/ui-ux-pro-max | 7 | 2 | missed `design-system`, `design`, `brand`, `banner-design`, `slides` |
| Leonxlnx/taste-skill | 13 | 2 | rest are style variants — evidence its dials generalize |
| anthropics/skills | 17 | 3 (+5 by hand) | remainder is the document-format family, declined by name |

**Process finding.** A subagent report that states a count and details a
subset is an unenumerated set claim. AGENTS.md's set rule was being
applied to the pack's own text and not to inbound reports. The fix that
worked is mechanical, not attentional: `ls` every member directory and
diff against the names appearing in the report. Candidate for promotion
to a repo-binding rule if it recurs — one occurrence is not a pattern.

## Declined, with reasons

Multi-harness packaging (18-way vendoring is how a 3.2MB skill becomes
59MB; Claude-Code-only is locked, the porting doc is the recipe if demand
appears) · machine-local memory stores (repo-owned memory is the identity)
· runtime engines: Python hooks, Node detectors, puppeteer, Python-over-CSV
search · binary payloads: fonts, CSVs, screenshots · per-step model
choreography (couples a skill to a model lineup) · numeric scoring, both
0–100 and 0–4 (score theater; code-review's README documents a scorer its
command does not implement, which demonstrates the hazard) · prose-pressure
enforcement (`<EXTREMELY_IMPORTANT>`, "skip a step = lying" — prose decay
is why check.sh exists) · superpowers' brainstorm hard gate (overrides the
user's chosen mode; CONDUCT rules 1 and 5 — the compatible half is 4.9's
offer) · generative persona framing inside a detective skill · stack-choice
advice that dates fast (`prototype`, `pick-ui-library`) · PR-watching
(`babysit` — real gap, but wave 7; /ship stops at the PR by design) ·
`version-bump` (4.1 ships VERSION/CHANGELOG guarded) · artifact generation
for end users (docx/pdf/pptx/xlsx, slides, banners, logos).
