# acstack

Personal skill pack for Claude Code: planning, journaling, subtask execution,
auditing, and database-migration pre-flight.

Five skills, one discipline: plans with runnable exit criteria, journals with
exact numbers, decisions that get superseded instead of deleted, and scores
that are never inflated.

Full documentation lands with the skills. See `skills/` for the pack contents.
